Coleção de exercícios e projetos de front-end desenvolvidos durante o **1° ano de Sistemas de Informação na FIAP**.  
Foco em lógica com JavaScript, manipulação do DOM, formulários e renderização dinâmica de dados.

---

## 📁 Projetos

### 🎓 Calcular Notas — `calcular-notas/`
Sistema de controle de notas no modelo de avaliação da FIAP.  
O aluno insere os 3 Checkpoints (os 2 maiores são aproveitados), 2 Sprints e o Global Solution.  
O sistema calcula automaticamente a média semestral ponderada e exibe o histórico em tabela.

> `DOM` · `formulário` · `sort()` · `cálculo de média ponderada`

---

### 🚗 Lista de Carros — `carros-lp/`
Landing page de uma concessionária com catálogo de carros renderizado dinamicamente a partir de um array de objetos.  
Conta com **filtro por categoria** via botões e **barra de busca** com histórico de pesquisas realizadas.

> `DOM` · `array de objetos` · `filtros` · `Intl.NumberFormat` · `cards`

---

### 🛋️ Catálogo de Móveis — `catalogo-moveis/`
Catálogo visual de produtos de uma loja de móveis, com CSS próprio e imagens de produto.  
Layout responsivo com grid de cards.

> `HTML` · `CSS` · `Grid Layout`

---

### 👤 Criar Conta — `criar-conta/`
Formulário de criação de conta com campos de usuário, senha, e-mail, data de cadastro e tipo de conta.  
Os dados são inseridos dinamicamente em uma tabela após o envio, sem recarregar a página.

> `DOM` · `formulário` · `createElement` · `forEach`

---

### 🏨 Grid Hotel — `ex-grid-hotel/`
Layout de hotel construído com CSS Grid e Font Awesome.  
Exercício de estruturação de página com seções de imagem, destaque e navegação.

> `CSS Grid` · `Font Awesome` · `Google Fonts`

---

### 🌐 Landing Page XYS — `landing-page-XYS/`
Landing page institucional para a marca fictícia **XYZSYS**.  
Desenvolvida com CSS puro, Google Fonts (Montserrat) e layout responsivo.

> `HTML` · `CSS` · `Responsivo` · `Google Fonts`

---

### 🏍️ Motos Elétricas — `motos-forms/`
Dois exercícios sobre motos elétricas com abordagens diferentes:
- **Ex-01** — renderiza os dados em **tabela** com preço formatado em R$
- **Ex-02** — renderiza os mesmos dados em **cards** com Bootstrap

> `DOM` · `ES Modules` · `import/export` · `Intl.NumberFormat` · `Bootstrap`

---

### 🎮 Sax Games — `sax-games/`
Loja de games com formulário de compra.  
Aplica **descontos por tipo de cliente** (B = 10%, C = 20%), calcula o valor final e exibe o parcelamento.  
Os pedidos são adicionados dinamicamente em uma tabela com histórico.

> `DOM` · `formulário` · `desconto` · `parcelamento` · `ES Modules`
